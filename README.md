# 🐼 Свод мероприятий

Интерактивный дашборд для отслеживания мероприятий по 7 организациям с визуализацией данных, поддержкой двух языков (русский/казахский) и двух тем (светлая/тёмная).

## ✨ Возможности

### Основные функции
- **Диаграммы**: визуализация распределения мероприятий по организациям
- **Организации**: детальные карточки для каждой организации
- **Таблицы данных**: редактируемые таблицы с мгновенным обновлением диаграмм
- **Два языка**: русский (RU) и казахский (KZ)
- **Две темы**: светлая и тёмная с плавным переключением
- **Авторизация**: защита редактирования данных паролем
- **Автосохранение**: данные сохраняются в localStorage

### Мобильная оптимизация 📱
- **Нижняя навигация**: удобная навигация на смартфонах
- **Кнопка "Наверх"**: быстрый возврат к началу страницы
- **Адаптивный дизайн**: оптимизация для всех размеров экранов
- **Touch-friendly**: увеличенные тач-таргеты для мобильных устройств
- **Производительность**: отключение тяжёлых эффектов на мобильных
- **Safe area**: поддержка устройств с вырезом (iPhone X и новее)
- **PWA-ready**: готов к установке как веб-приложение

### Производительность
- **Оптимизированные анимации**: плавные переходы без тормозов
- **Lazy loading**: ленивая загрузка компонентов
- **Мемоизация**: использование React.memo и useMemo
- **Минимальный размер**: ~60KB gzip для JavaScript

## 🚀 Развёртывание на GitHub Pages

### Автоматический деплой через GitHub Actions

1. Загрузите проект в репозиторий GitHub
2. GitHub Actions автоматически:
   - Установит зависимости
   - Соберёт проект
   - Задеплоит на GitHub Pages
3. Сайт будет доступен по адресу: `https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПО/`

### Ручной деплой

```bash
# Установка зависимостей
npm install

# Сборка проекта
npm run build

# Папка dist готова к загрузке на GitHub Pages
```

Загрузите содержимое папки `dist` в ветку `gh-pages` или настройте GitHub Pages на папку `/docs`.

Для редактирования данных в таблицах необходимо войти в систему:

## 📱 Мобильные возможности

### Нижняя навигация
На мобильных устройствах (< 768px) появляется удобная нижняя навигация с иконками:
- 📊 Диаграммы
- 🏢 Организации
- 📋 Таблицы

### Кнопка "Наверх"
Появляется при скролле вниз для быстрого возврата к началу страницы.

### Оптимизации
- Отключение glow-эффектов на мобильных для производительности
- Увеличенные тач-таргеты (минимум 44px)
- Адаптивные размеры шрифтов и отступов
- Поддержка safe area для устройств с вырезом
- Оптимизация для iOS Safari и Android Chrome

## 🎨 Особенности дизайна

- **Маскот**: милая панда в логотипе и фоновых силуэтах
- **Анимации**: плавные переходы между темами, анимированные диаграммы
- **Glow-эффекты**: атмосферное свечение в тёмной теме (отключается на мобильных)
- **Градиенты**: красивые градиентные фоны
- **Доступность**: семантическая разметка, ARIA-атрибуты
